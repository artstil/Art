## 2025-03-01 - Missing Accessibility Attributes on Icon-Only Buttons
**Learning:** Found a pattern across the application where multiple icon-only buttons (like calendar navigation, mobile timeline play/pause, floating action buttons, and modal close buttons) lacked `aria-label` attributes and proper keyboard focus indicators (`focus-visible`). This makes these essential navigation and interaction elements difficult for screen reader users to interpret and keyboard users to navigate.
**Action:** Always ensure that icon-only buttons have descriptive `aria-label` attributes (e.g., "Close daily diary" instead of just having an 'X' icon) and utilize `focus-visible:ring-2 focus-visible:outline-none` utility classes to guarantee keyboard accessibility is visually prominent without degrading the experience for mouse users.
