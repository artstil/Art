## 2025-02-23 - Accessibility of Icon-Only Buttons
**Learning:** Found a common pattern across this application where icon-only buttons (like modal close buttons, floating action buttons, and calendar navigation controls) lack accessible names (`aria-label`) and visible focus indicators (`focus-visible`). This makes the application difficult to use for screen reader users (who cannot determine the button's purpose) and keyboard users (who cannot see which element has focus).
**Action:** Added `aria-label` attributes to provide accessible names, `aria-hidden="true"` to inner SVG icons to prevent redundant or confusing screen reader announcements, and Tailwind `focus-visible` utility classes (`focus-visible:ring-2 focus-visible:outline-none focus-visible:ring-theme-primary`) to ensure a clear visual focus state for keyboard navigation. This pattern should be applied consistently to all new icon-only buttons.
