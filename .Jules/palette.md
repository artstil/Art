## 2024-10-03 - Accessible Focus States for App Interactions
**Learning:** Found an accessibility pattern where icon-only buttons across the app lacked ARIA labels and distinct keyboard focus indicators. Since the app heavily relies on `lucide-react` icons (like Play/Pause, Close `X`, and chevrons), standard `button` elements need explicit semantic names and visible focus styling for keyboard and screen reader users to understand and navigate them effectively.
**Action:** Ensure all interactive elements, particularly those that use icons instead of text, consistently implement explicit `aria-label` attributes describing their action and use `focus-visible` utility classes (e.g., `focus-visible:ring-2 focus-visible:outline-none focus-visible:ring-theme-primary`) to provide clear visual feedback without compromising mouse hover UX.
