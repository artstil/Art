## 2023-10-27 - Icon-Only Button Accessibility Pattern
**Learning:** Found a persistent pattern where custom interactive elements like Floating Action Buttons (FABs) and modal dismiss buttons (often using 'X' icons) lack `aria-label`s and proper focus states in React applications. While standard text buttons usually fall in line, these visual-only UI elements are easily missed by developers, rendering them completely opaque to screen readers and difficult to track for keyboard navigators.
**Action:** When auditing or building new custom components (like modals or sidebars), explicitly check all icon-only buttons for `aria-label` attributes and ensure they have `focus-visible` states (e.g., `focus-visible:ring-2` in Tailwind) to maintain parity for visually impaired and keyboard-only users.
