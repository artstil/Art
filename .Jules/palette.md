## 2024-05-24 - Screen Reader Friendly and Keyboard Accessible Icon Buttons\n**Learning:** Icon-only buttons without explicit labels and visual focus states represent a significant accessibility barrier. Without an `aria-label`, screen readers cannot describe the button's action, and without `focus-visible` utility classes, users navigating via keyboard cannot easily determine which element has focus, leading to a frustrating experience. It is essential to remember that `aria-hidden="true"` should be added to the interior SVG icons to prevent redundant or confusing screen reader announcements when a parent `aria-label` exists.\n**Action:** For every icon-only button added or reviewed in the application (e.g., modals, navigation, FABs), always enforce a combination of a descriptive `aria-label`, an interior SVG with `aria-hidden="true"`, and a visible focus indicator (like `focus-visible:ring-2 focus-visible:outline-none focus-visible:ring-theme-primary`).
