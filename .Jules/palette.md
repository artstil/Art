## 2023-10-24 - Identifying and Enhancing Icon-Only Elements for Screen Readers
**Learning:** Icon-only buttons (like `X` for close, or `ChevronRight`/`Left` for pagination), even when their action seems visually obvious, require explicit `aria-label` attributes for screen readers. Furthermore, the internal SVG icon itself must be marked with `aria-hidden="true"` to prevent screen readers from attempting to read the raw SVG or creating redundant announcements, thereby violating WCAG guidelines (like Double-Reading). Finally, visually hiding elements isn't enough; interactive elements must maintain clear visible focus states (`focus-visible`) for keyboard navigation.
**Action:** Always inspect icon-only interactive elements for missing `aria-label`s and ensure that child SVGs possess `aria-hidden="true"`. Apply `focus-visible` utility classes (`focus-visible:ring-2`, `focus-visible:outline-none`) systematically to all interactive elements to support robust keyboard accessibility.
